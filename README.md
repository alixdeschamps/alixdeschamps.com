# alixdeschamps.com

Portage en Astro du thème Pelican [Solar](https://github.com/lowtechmag/solar), conçu pour [solar.lowtechmagazine.com](https://solar.lowtechmagazine.com). Police Luciole (CC BY 4.0).

La feuille de style `src/styles/style.scss` vient du thème Solar, publié sous licence **AGPL-3.0** par Marie Otsuka et Roel Roscam Abbing. Le reste du code est propre à ce projet.

Les miniatures sont tramées par `scripts/dither.mjs` dans `public/dithers/`. Le script tourne automatiquement avant `npm run dev` et `npm run build`.

```bash
npm install
npm run dev
```
